# Variables y tipos de datos

Una variable permite guardar un dato que puede utilizar el programa.

## Tipos básicos

| Tipo | Uso | Ejemplo |
|---|---|---|
| `int` | Números enteros | `int edad = 16;` |
| `double` | Números decimales | `double nota = 7.5;` |
| `char` | Un carácter | `char letra = 'A';` |
| `boolean` | Verdadero o falso | `boolean aprobado = true;` |
| `String` | Texto | `String nombre = "Ana";` |

!!! tip "Consejo"
    Elige el tipo de dato que corresponda al valor que necesitas almacenar.

## Declaración

```java
int contador = 0;
contador = contador + 1;
```

# Conceptos básicos

Java es un lenguaje de programación orientado a objetos. Los programas suelen organizarse en clases y métodos.

## Estructura de un programa

Un programa Java básico contiene una clase y el método `main`, que es el punto de entrada.

!!! note "Importante"
    El nombre del archivo debe coincidir con el nombre de la clase pública.

## Elementos habituales

- **Clase:** estructura que contiene código.
- **Método:** bloque de instrucciones que realiza una tarea.
- **Instrucción:** orden que ejecuta el programa.
